Cybersecurity

Critical NGINX flaw (CVE-2026-42533) can crash workers, may allow remote code execution

F5 shipped fixes for a critical nginx heap buffer overflow that a remote, unauthenticated attacker can trigger with crafted HTTP requests. CVE-2026-42533 is patched in nginx 1.30.4 (stable), 1.31.3 (mainline) and NGINX Plus 37.0.3.1; exploitation can crash worker processes for denial of service, and where ASLR is disabled or bypassed, F5 says it may allow remote code execution. Given nginx's ubiquity across Indian and Southeast Asian web infrastructure, immediate patching is advised. (Published: 2026-07-19)
- The Hacker News

SonicWall SMA zero-days exploited in the wild before disclosure to gain root access

Volexity attributed exploitation of two SonicWall Secure Mobile Access 1000-series VPN vulnerabilities — CVE-2026-15409 (CVSS 10.0) and CVE-2026-15410 (CVSS 7.2) — to a previously undocumented threat actor tracked as UTA0533, active since at least June 22, 2026, before public disclosure. The flaws can be chained for arbitrary command execution and full appliance takeover; SonicWall released patches this week, and organizations running SMA 1000 appliances should patch and hunt for compromise. (Published: 2026-07-19)
- The Hacker News

Sandworm subgroup UAC-0145 uses fake ClickFix CAPTCHAs to deliver data-stealing malware

CERT-UA reported that UAC-0145, a sub-cluster of the GRU-affiliated Sandworm group, is using fake CAPTCHA checks on compromised websites to trick targets into pasting PowerShell commands that install malware including the GHETTOVIBE VBS payload and the SCOUTCURL reconnaissance script. While the current campaign targets Ukraine, ClickFix-style social engineering has been spreading globally and is a technique regional security teams in India and Southeast Asia should brief users on. (Published: 2026-07-19)
- The Hacker News
