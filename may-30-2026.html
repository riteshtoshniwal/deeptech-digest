🤖 Cybersecurity: AI Used in Live Attack for First Time in Asia

Attackers Use LLM Agent for Post-Exploitation After Marimo CVE-2026-39987 Exploit

In a landmark moment for cyber threat intelligence, researchers at Sysdig documented the first observed instance of a threat actor deploying a large language model (LLM) agent to autonomously carry out post-exploitation activity. After gaining initial access via CVE-2026-39987 — a critical remote code execution vulnerability in the Marimo Python notebook framework — the attacker handed off control to an AI agent, which conducted lateral movement across four pivot points, extracted two cloud credentials, retrieved an SSH private key from AWS Secrets Manager, and exfiltrated an internal PostgreSQL database — all in under two minutes. Commands were composed in real time, adapting dynamically to each step's output. Cloudflare Workers were used as a per-request egress pool across 11 distinct IPs in 22 seconds to evade per-source-IP detection. (Published: 2026-05-29)

Silver Fox Deploys ABCDoor Malware via Income Tax Phishing Targeting Indian Organizations

The China-linked Silver Fox APT group launched a sophisticated tax-themed phishing campaign against Indian organizations, impersonating the Income Tax Department of India to distribute a newly identified Python-based backdoor called ABCDoor, alongside the well-known ValleyRAT malware.
